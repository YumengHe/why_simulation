2.6 NeRF: from cabinet photos to new views

Specific method · Neural Radiance Field (NeRF)

First, train: use multiple views of the cabinet and their camera information to train a network representing the cabinet in 3D. Repeatedly render images, compare with the photographs, and update the network.

Then, render: use the saved network and a new virtual camera position and settings to produce another view of the same cabinet. No photograph from that new angle is needed.

2.6.1 Photograph the cabinet

Take overlapping photographs from several positions. Keep the cabinet, drawer, and door still. Each photograph shows the same scene from a different viewpoint.

The original NeRF is trained separately for each scene. Photographs of this cabinet provide the training images: the network learns a description of this particular cabinet from those views.

The three views illustrate the image collection step. Reconstruction may use many more photographs to cover the scene.

2.6.2 Prepare images and camera parameters

The NeRF training pipeline takes the scene’s images and each image’s camera position, orientation, and lens parameters as input. Position specifies where the camera was; orientation specifies which way it pointed. Lens parameters, such as focal length, determine how the scene projects onto the image.

Use the camera estimates from Section 2.4

NeRF training sequence

  1. Estimate the cameras. COLMAP processes the cabinet photographs and estimates the camera parameters associated with each image.
  2. Calculate rays and sample positions. NeRF’s renderer uses the camera parameters to construct a ray through a selected pixel, then samples 3D positions along that ray.
  3. Query the neural network. Each sample position and its viewing direction enter the network, which predicts a color and density.
  4. Render and compare. The renderer combines those predictions into a pixel color and compares it with the corresponding pixel in the cabinet photograph.
  5. Update the network. The training algorithm adjusts the network’s numerical settings, called weights, to reduce the color error. Steps 2–5 repeat across pixels and camera views.

COLMAP supplies camera estimates during data preparation. The repeated training loop updates the NeRF network. The photographs provide target colors; the renderer calculates the positions and directions sent to the network. Section 2.6.4 illustrates the ray and sample positions for one cabinet pixel.

2.6.3 Create a network that can answer questions about space

NeRF stands for Neural Radiance Field. The name describes a learned rule for answering two questions at a place in 3D:

Color
The color a location contributes when viewed from a particular direction. At the blue drawer front, the expected contribution is blue.
Density
How strongly does a small interval here contribute and block what is behind it? Air should contribute almost nothing; the blue panel should strongly affect the picture.

Neural refers to the learned program. Radiance refers to the light or color seen from a direction. Field means the program can answer at different positions throughout 3D space. Density here controls visibility, not the cabinet’s weight. The original project explains this representation.

The network begins with untrained weights. During training, the photographs provide target pixel colors, while the renderer supplies the position-and-direction queries.

2.6.4 Generate the 3D positions from a camera pixel

In this example, COLMAP provides the estimated camera position, orientation, and lens parameters, as described in Section 2.6.2: Prepare images and camera parameters. NeRF’s renderer uses these outputs to calculate the sample positions and viewing directions:

  1. It selects a pixel in one training photograph.
  2. It uses COLMAP’s estimates of the camera position, orientation, and lens parameters to calculate the pixel’s ray: a line of sight extending into the scene.
  3. It samples several distances along that ray. Each distance gives a 3D sample position.
  4. It sends each position and the ray’s direction to the network. Points on the same ray share the same direction.

A small coordinate example

Here, X points right, Y points toward the cabinet, and Z points up. Coordinates are in meters. The camera is at (0, −3, 0.64). The selected ray points straight along +Y, so its direction is (0, 1, 0).

For P2, start at the camera and move 2 m along +Y: the Y coordinate changes from −3 to −1. X and Z stay the same. Other pixels generally produce rays pointing in different directions. In practice, the renderer uses many samples, not just these three.

Each sampled 3D position, together with the ray’s viewing direction, forms an input to the NeRF neural network. For P2, the input is position (0, −1, 0.64) and direction (0, 1, 0). The network predicts a color and density for each sample. Section 2.6.5 explains how the renderer combines these predictions along the ray to produce one pixel’s color.

A prediction that represents this cabinet well assigns low density to the air and blue color with high density near the drawer front:

P2 · air

The renderer combines the sample colors from near to far. Density and the distance represented by each sample determine how strongly it contributes and how much of the view passes through to later samples. This calculation is called volume rendering. It uses many samples along the ray; P1–P3 are three labeled locations within that process. Rendering details in the paper.

The combined color is written into the original selected pixel. In this example, the drawer front makes that pixel blue.

From one pixel to a complete cabinet image

The renderer repeats the same calculation for every pixel, using a different ray for each one. The result is an ordinary 2D color image, like this cabinet view:

One ray gives one pixel. The ray through P1–P3 gives the blue pixel discussed above.

All the rays give the whole picture. Rays through the drawer produce blue pixels; rays through the door produce gold pixels; rays through the body produce teal pixels. Rays that pass through empty space leave the white background visible.

Color and density work together. Color supplies the possible colors along a ray. Density helps determine how much each sample contributes and how much is hidden behind it. After combining them, the finished pixel contains a single color.

The prediction can still be wrong. Section 2.6.6 compares the rendered pixels with the corresponding photograph pixels and uses their differences to update the network.

2.6.6 Compare with the photograph, then learn

In this example, the predicted drawer is gray, but the reference image shows blue. Both images use the same camera, so corresponding pixel colors can be compared directly.

  1. Render a prediction. Generate rays, query the network, and combine its answers.
  2. Measure the error. Compare the predicted colors with the corresponding photo pixels.
  3. Adjust the network’s weights. The training algorithm calculates changes intended to reduce that error.
  4. Repeat with more pixels and views. Render again with the updated network and compare again.

The photographs provide target pixel colors, without labeling the density at P3 or the drawer’s surface position. Views from other cameras help constrain the 3D arrangement: a misplaced panel might match one view but appear in the wrong place in another.

Rendering and comparison are repeated throughout training. As the network’s weights change to reduce image errors, its 3D description improves. One network is trained to account for the cabinet across the input views. The original training procedure.

2.6.7 Save the trained NeRF and render another view

Training produces a NeRF network that represents this cabinet. Its learned weights are saved so the same network can be used again. The images rendered during training help check and improve that network, as described in Section 2.6.6.

Train the NeRFCabinet photographs + their camera parametersA trained network representing the cabinet in 3D
Render a viewThe trained network + a chosen virtual cameraA 2D image of the same cabinet from that camera

To view the cabinet from farther to the right, move the virtual camera to the right. Keep the trained network unchanged. The renderer calculates new rays, queries the same network for color and density, and combines those outputs into a new image using the process in Section 2.6.5.

Rendering a viewpoint absent from the training photographs is called novel-view synthesis. This is a main use of NeRF: showing the same scene from another viewpoint. Each view is rendered directly from the trained network; the previously rendered image is not an input to this step. NeRF project and examples.

An unseen back or interior can still be wrong. Good-looking views do not guarantee accurate hidden geometry, moving joints, or mass.

The stored scene differs from 3DGS: 3DGS adjusts a set of blobs; NeRF adjusts a network. Both use rendered images to check a 3D representation against photographs.
