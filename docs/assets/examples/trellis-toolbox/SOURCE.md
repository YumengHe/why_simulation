# TRELLIS toolbox example

Source: https://microsoft.github.io/TRELLIS/

The original input and output are from the authors' **Image to 3D Asset** gallery:

- Input: https://microsoft.github.io/TRELLIS/assets/img2/images/toolbox.png
- Video: https://microsoft.github.io/TRELLIS/assets/img2/videos/toolbox.mp4

`input.png` is the unmodified input image downloaded from that page. The authors
state that these image prompts were made with DALL·E 3.

`gaussians.png` and `mesh.png` are unmodified frames 3 and 8 from an extraction
at one frame per second of the 10-second source video. The corresponding camera
views appear in its first (appearance) and second (geometry) halves. The authors
state that appearance is rendered from 3D Gaussians and geometry from meshes.
The geometry display is not a triangle-wireframe view. Neither result was
generated by this book's authors.
