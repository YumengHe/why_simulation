Why Simulation?

    Overview

    Why simulation? It lets us try an action in a modeled world, calculate what happens, and repeat the experiment with different conditions.

    This free online book follows one familiar task: opening a drawer. We begin with how AI models understand instructions, then build the 3D object and describe how it moves. Simple explanations, illustrations, and moving examples connect these ideas.

    1. Language, vision, and robot actions — understanding a request, reading a picture, and choosing a movement.
    2. 3D representation, rendering, reconstruction, and generation — what is stored, how it becomes an image, and how methods create it.
    3. Articulated objects — parts, joints, and URDF files.
    4. Simulation — preparing a physical model, testing forces, and adding robot interaction.
